# Escape Room - Vue 3 + Vite

Projeto convertido a partir do HTML/CSS/JS original.

## Como rodar

1. use ls para achar o lugar certo
   ```
   cd escape-room

2. Instale dependências:
   ```
   npm install
   ```
3. Rode em desenvolvimento:
   ```
   npm run dev
   ```

## Estrutura criada

- `src/` - código fonte (components, views, explicações do funcionamento do código)
- `public/imagen/` - as imagens usadas pelo jogo
